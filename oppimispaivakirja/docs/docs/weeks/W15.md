# W15: Käyttöliittymä, profiilit ja malliasetukset

**Päivät:** 6.4.2026 - 12.4.2026

## Valinnat käyttöliittymästä ajoon

Rakensin pysyvämpää käyttöliittymää profiileille ja malliasetuksille. Tavoitteena oli, että ruudulla tehty valinta kulkee oikeasti ajonaikaiseen ytimeen eikä jää vain asetustiedoston koristeeksi.

## Päästä päähän tarkoittaa oikeasti päästä päähän

Käytettävyys riippuu siitä, kulkeeko valinta päästä päähän. Jos profiili tai malli näkyy käyttöliittymässä mutta ei vaikuta ajon ominaisuuksiin ja palveluntarjoajalle lähtevään pyyntöön, käyttöliittymä lupaa enemmän kuin järjestelmä tekee.

Komentoriviparametrit olisivat riittäneet omaan käyttöön hetken aikaa. Pysyvä näkymä vähentää muistettavien asioiden määrää, mutta sen täytyy näyttää selvästi, mikä profiili ja malli ovat aktiivisia.

## Seuraava skenaario

Mallin vaihto tarvitsee nyt päästä päähän ulottuvan skenaarion. Sen pitää tarkistaa valinta, tapahtuman metatieto ja TUI:n palautunut tila samassa ajossa.
