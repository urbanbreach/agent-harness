# W20: Valmistumissäännöt ja simulaation löytämät esteet

**Päivät:** 11.5.2026 - 17.5.2026

## Milloin tehtävä on valmis

Keskityin tehtävän valmistumissääntöihin ja simulaation löytämiin esteisiin. Tärkeimmäksi kysymykseksi nousi, milloin järjestelmä saa oikeasti ilmoittaa työn valmistuneeksi.

## Valmis tarvitsee todisteen

Valmis ei tarkoita vain sitä, että suoritus päättyi ilman virhettä. Tarvitsen havaittavan lopputuloksen, kuten oikean tapahtuman, päivittyneen projektion, artefaktin tai käyttäjälle näkyvän tilan.

Pelkkä valmistumisviesti olisi ollut helppo tuottaa, mutta vaikea todistaa oikeaksi. Simulaatio on arvokas juuri siksi, että se löytää tilanteet, joissa järjestelmän väite ja havaittava lopputulos eroavat toisistaan.

## Seuraava sääntö

Jokainen valmistumispolku saa koneellisesti tarkistettavan lopputuloksen ennen käyttöliittymätekstin kirjoittamista.
