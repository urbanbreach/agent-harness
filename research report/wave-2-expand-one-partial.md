## Strongest surviving implementation verdicts

1. Make dashboard a true full-surface mode, but add exact transcript anchor capture before entry; Harness currently preserves focus/follow only.
2. Keep one Harness fold authority and add dense-run truncation, user expansion, response navigation, turn position, and pin-reserve behavior there.
3. Add citation-fence parsing/path-based syntax lookup, rich table wrapping/cell formatting, hyperlink propagation, and incremental open-fence highlighting; keep Harness structural diff fences.
4. Make multiline state real and visible, add atomic multiline paste chips, and separate send-now, cancel-and-replace, and non-cancelling interject semantics.
5. Add command argument metadata, arg-phase suggestions, match highlighting, mid-text slash detection, and runtime extension sources while preserving deterministic Harness ranking.
6. Do not reimplement status animation: Harness frames/cadence already match Grok. Add terminal-safe ASCII/CP437 spinner fallbacks instead.
7. Consolidate reusable modal geometry/tab/shortcut behavior. Harness close hit target already exceeds Grok's and must not regress.
8. Fix token-to-runtime theme drift and add an optional Basic-color terminal-native cap. Preserve Harness accent tokens, logo, names, and voice.
9. Add follow-aware scrollbar dimming. Harness already has timed gesture classification; investigate only the later accumulator/coast pipeline.
10. Wire the existing resize debouncer. Do not adopt estimated off-screen transcript heights until exact-anchor behavior can be preserved and proven.
11. Separate Disconnected from Reconnecting, disable Stop while disconnected, and remove “Reconnecting live state…” until a runtime reconnect path is actually wired.
12. Add an emulator-backed PTY assertion lane with durable evidence; current smoke checks and TestBackend snapshots cannot detect terminal control-state failures.

## Refutations and corrections

- Exact dashboard restoration is not present: transcript anchor capture is currently `None`.
- Harness has semantic verb aggregation; only dense-run truncation/expansion remains.
- Harness has OSC-8 encoding/tests; the integration is orphaned rather than absent.
- Harness already accepts Tab in slash completion; inconsistent dropdown semantics remain.
- Harness status animation cadence already matches Grok.
- Harness close hit target is larger than Grok's.
- Harness has timed gesture classification; the open question is downstream clamping/coast, not total absence.
- Visible-window estimation is an architectural trade, not an automatic improvement over exact full-history measurement.
- “Reconnecting live state…” is false under the current TUI lifecycle, which simultaneously tells the operator to reopen.
- Ratatui TestBackend string snapshots are not equivalent to terminal-emulator assertions.
