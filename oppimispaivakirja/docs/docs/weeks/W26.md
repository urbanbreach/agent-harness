# W26: Tunnistautuminen, `ProviderId` ja käyttöönotto

**Päivät:** 22.6.2026 - 28.6.2026

## Identiteetti omaksi tyypikseen

Rakensin tunnistautumisliitännäistä, `ProviderId`-tyyppiä, yhteyden käyttöönottoa ja sumeaa komentohakua. Tunnistautuminen alkoi näyttää omalta järjestelmärajaltaan eikä vain yhdeltä kirjautumispainikkeelta.

## Rustin tyypit estävät sekoittumista

Tunnistautumisessa yhdistyvät identiteetti ja salaisuuksien käsittely. `ProviderId`-tyyppi estää eri tunnisteiden sekoittumisen jo käännösvaiheessa. Tämä konkretisoi hyvin sen, miksi Rustin tyypeistä on hyötyä muuallakin kuin muistiturvallisuudessa.

Palveluntarjoajan nimen välittäminen tavallisena merkkijonona olisi ollut aluksi nopeaa. Epäselvät tunnisteet ja väärät asetuskohteet olisivat silloin jääneet vasta ajonaikana löytyviksi virheiksi.

Käyttöönotto tarvitsee vielä virhematriisin, joka erottaa käyttäjän peruutuksen, vanhentuneen tunnisteen ja väärän palveluntarjoajavalinnan.
