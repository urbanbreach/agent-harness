01 / Design thesis

Power without the black box.

01

Append-only truth

Every meaningful transition enters an ordered JSONL event stream. State is derived, not guessed.

02

One authority

The coordinator owns scheduling, permissions, hooks, compaction, tools, and lifecycle decisions.

03

Safe replay

Inspection rebuilds state without invoking providers, tools, hooks, MCP servers, or network calls.

04

Bounded delegation

Child sessions remain observable, cancellable, and linked to their parent through durable lineage.

02 / Workspace map

Six crates. Strict boundaries.

harness-core

Runtime authority

Coordinator, events, projections, configuration, permissions, redaction, lineage, and atomic hashline edits.

harness

CLI surface

Interactive launch, headless runs, authentication, doctor, config tools, replay, and session commands.

harness-providers

Model boundary

Streaming provider abstraction, OpenAI-compatible transport, OAuth support, mock fixtures, and usage metadata.

harness-tools

Native capability

Workspace operations, shell execution, research, language intelligence, skills, delegation, and session inspection.

harness-tui

Operator surface

Compose-first terminal shell with live events, permission prompts, diffs, replay, and session navigation.

harness-testkit

Proof layer

Deterministic fakes, simulation helpers, PTY end-to-end checks, native evidence, and validation utilities.

04 / Safety model

Control lives in the runtime.

Guardrails are structural rather than cosmetic. The coordinator is the only authority allowed to append events, resolve permissions, schedule tasks, apply lifecycle transitions, or coordinate compaction.

A
Permission firstNative tool execution cannot begin before the matching capability policy resolves.
B
Replay is inertSession inspection reads replay-derived data only and never resumes external work.
C
Edits are atomicHashline anchors are validated, overlaps rejected, and file writes committed atomically.
D
Metadata is redactedRaw requests, responses, authentication headers, cookies, keys, and hidden reasoning are not persisted.

07 / Get started

Build it. Validate it. Run offline.

The deterministic mock path exercises a complete turn before credentials or provider transport enter the equation.

agent-harness — shell
# Build the CLI
$ cargo build -p harness

# Validate config and local readiness
$ target/debug/harness --config configs/harness.example.jsonc config validate
$ target/debug/harness --config configs/harness.example.jsonc doctor

# Prove the complete path offline
$ target/debug/harness run --mock "Hello from Harness" \
    --out prompt.events.jsonl --print-run-dir

# Open the interactive terminal shell
$ target/debug/harness
