# W18: Kestävä keskusteluhistoria ja checkpoint-kompaktio

**Päivät:** 27.4.2026 - 3.5.2026

## Pitkän session muistia rakentamassa

Rakensin kestävää keskusteluhistorian toistoa ja checkpoint-kompaktiota. Pitkä sessio tarvitsee tiivistämistä, mutta samalla alkuperäinen tapahtumaketju pitää säilyttää tarkastettavana.

## Historiaa ei saa hävittää

Tapahtumalähteisyydessä historiallisen lokin ja palveluntarjoajalle annettavan tiivistetyn kontekstin suhde täytyy määritellä tarkasti. Kompaktio helpottaa pitkän session jatkamista, mutta se ei saa kirjoittaa alkuperäistä historiaa uusiksi.

Vain muuttuvan nykytilan säilyttäminen olisi vienyt vähemmän tilaa. Silloin virheen jäljitys olisi kuitenkin päättynyt viimeiseen yhteenvetoon. Checkpoint toimii paremmin omana artefaktinaan ja tapahtumanaan, joka ei hävitä sitä edeltävää lokia.

## Seuraava kuormitusskenaario

Kompaktio tarvitsee vielä kuormitusskenaarion, joka vertaa toistoa ennen tiivistystä ja sen jälkeen. Olennaisten projektioiden pitää pysyä samoina.
