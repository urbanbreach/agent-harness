# Issue delivery

Use this starter skill when finishing a repository issue from triage through closeout.

## Checklist
1. Restate the desired outcome and keep scope aligned with the issue.
2. Prefer shipped examples and tests over assumptions about local machine state.
3. Update user-facing docs when behavior or onboarding changes.
4. Run focused verification before claiming completion.
5. Record the final evidence in the commit message and issue closeout comment.

## Closeout reminders
- Mention changed files, verification performed, and remaining risks.
- Keep issue comments short and link them to the landing commit hash.
- Do not start follow-up issues unless explicitly requested.
