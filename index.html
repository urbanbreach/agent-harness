01 / Design thesis

Capability without opacity.

01

Events are truth

Every meaningful transition is written to an ordered, append-only JSONL event stream.

02

One authority

The coordinator owns scheduling, permissions, hooks, compaction, tools, and lifecycle.

03

Replay never acts

Inspection derives state without invoking providers, tools, hooks, MCP servers, or the network.

04

Delegation has lineage

Child sessions remain bounded, observable, cancellable, and connected to their parent.

02 / Architecture

Six crates. Clear boundaries.

crates/harness-core

Runtime authority

Coordinator, events, stores, permissions, projections, configuration, redaction, and atomic hashline editing.

crates/harness

CLI entrypoint

Interactive launch, headless runs, auth, config validation, doctor, replay, and session support exports.

crates/harness-providers

Model boundary

Streaming provider abstraction, OpenAI-compatible transport, Codex auth, mock fixtures, and usage metadata.

crates/harness-tools

Native capability

Safe file operations, shell execution, language intelligence, web access, delegation, skills, and session inspection.

crates/harness-tui

Operator surface

Compose-first terminal shell with live events, replay mode, permission prompts, diffs, and session navigation.

crates/harness-testkit

Proof layer

Deterministic fakes, simulations, PTY end-to-end helpers, native evidence, and validation utilities.

03 / Runtime flow

Intent becomes controlled execution.

Submit

A prompt enters through the TUI or headless CLI.

Stream

A provider emits normalized response and tool-call events.

Authorize

The coordinator resolves allow, deny, or ask before execution.

Execute

Native tools act inside workspace and capability boundaries.

Record

Results are redacted, appended, projected, and replayable.

04 / Tool surface

Useful by default. Gated by design.

Built-in tools cover workspace discovery, atomic edits, shell commands, structural and language search, provider-backed research, task delegation, and replay-derived session inspection.

Safety boundary: permission checks precede execution. Replay is side-effect free, and persisted provider metadata is redacted.

05 / Get started

Build once. Prove the path offline.

agent-harness — bash
# Build the CLI
$ cargo build -p harness

# Validate configuration and local readiness
$ cargo run -p harness -- --config configs/harness.example.jsonc config validate
$ cargo run -p harness -- --config configs/harness.example.jsonc doctor

# Exercise a complete deterministic turn without provider credentials
$ target/debug/harness run --mock "Hello from Harness" --out prompt.events.jsonl

# Open the interactive terminal shell
$ target/debug/harness
