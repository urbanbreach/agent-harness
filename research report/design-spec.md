# Delivery design specification

- Format: standalone Markdown, rendered to HTML only for QA evidence.
- Register: senior design-engineering audit; precise, restrained, implementation-ready.
- Structure: executive summary; parity definition; prioritized findings; detailed comparisons; implementation roadmap; verification matrix; unresolved gaps; methodology.
- Citations: inline repository `path:line` references and session artifact links.
- Branding rule: preserve Harness name, logos, marks, and product voice; transfer Grok Build's layout, interaction, motion, and finish rather than its brand identity.
- Tables: concise cells, no decorative emoji, stable headings.
- Figures: Mermaid only when it materially clarifies sequencing or architecture.
