# W24: Dialogit, päälle avautuvat ikkunat ja uudelleenyritykset

**Päivät:** 8.6.2026 - 14.6.2026

## Virhetilanne käyttäjän silmin

Kehitin TUI:n dialogeja, päälle avautuvia ikkunoita ja palveluntarjoajan uudelleenyritysten metatietoa. Virhetilanteen piti näkyä käyttäjälle riittävän tarkasti, mutta ilman arkaluonteisen palveluntarjoajadatan vuotamista ruudulle tai lokiin.

## Uudelleenyrityksen pitää näkyä

Virheiden käsittely on tärkeä osa käyttäjäpintaa. Uudelleenyrityksen metatiedosta on hyötyä vasta, kun käyttäjä näkee, mitä yritettiin, mikä muuttui ja mihin tilaan sovellus palasi.

Yleinen epäonnistumisviesti olisi ollut nopea toteuttaa. Se ei kuitenkaan auta erottamaan käyttöoikeusvirhettä, verkko-ongelmaa ja käynnissä olevaa uudelleenyritystä. Rakenteinen metatieto tekee palautumisesta ymmärrettävää.

## Seuraava virhepolku

Määrittelen uudelleenyritykselle käyttäjätekstin, näkyvän tilasiirtymän ja puhdistetun diagnostiikan yhtenä kokonaisuutena.
