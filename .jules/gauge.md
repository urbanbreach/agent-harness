## 2025-05-18 - Avoid allocations when normalizing keys for redaction
**Learning:** Redacting sensitive payloads allocates `Vec<String>` dynamically inside `redaction_marker_for_sensitive_key` via string splitting for every sensitive map key, which is heavily hit in event processing.
**Action:** Replace iterator allocations like `.collect::<Vec<_>>()` by lazily streaming string splits inside a custom segment matching function that works directly with `Iterator<Item = &str>`. Using `mut segments: impl Iterator<Item = &str>` prevents `Vec` allocations during case-insensitive segment match checks.
