# Archived verification evidence

Reference product names, source paths and test labels in the historical text
receipts were redacted to neutral reference labels on 4 October 2026. These
edited receipts are historical reports, not fresh runs or byte-for-byte copies
of their original logs. Source revisions, measurements and image bytes are
unchanged; original source/binary hashes describe the captured versions.

External reference capture adapters have been retired. Maintained Harness
fixtures and behavior tests remain under the owning crates' tests directories.
