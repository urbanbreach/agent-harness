# Node eval verification

JavaScript eval now uses a persistent Node.js worker and requires Node.js 24 or
newer on PATH. The Cargo lockfile falls from 1,065 to 537 packages; no Deno,
SWC, or V8 crates remain. The worker and its dependency-free Acorn parser ship
inside Harness, so no npm install is needed.

## Checks

- Workspace nextest with all features: 1,972 passed, 19 opt-in tests skipped.
- Minimum Node.js 24.0.0: all seven eval tests passed. Node.js 22.23.3 was
  rejected with the required version in the error. Missing Node is also tested.
- Four-language eval lane: JavaScript, Python, Ruby, and Julia passed, including
  eight coordinator/MCP integration tests.
- Workspace Clippy with all targets/features, formatting, build, diff whitespace,
  and static test-suite gates passed. CI YAML parsed successfully.
- All 54 conformance cells match the earlier embedded runtime's recorded results;
  intentional error wording and stack paths are excluded from comparison.
- Twelve PTY/xterm captures passed. Visual inspection confirmed clipped code,
  expanded output, and Unicode wrapping at 40 and 120 columns. Cleanup left no
  running process group or temporary sockets.

The branding gate retains five pre-existing findings in
`docs/evidence/tui-rewrite/runtime-state/post-measure-host.json:37` and
`plans/001-role-scoped-subagents.md:30,64,65,160`.

warmups and 10 cold/reset samples per language. These measure the public Session
