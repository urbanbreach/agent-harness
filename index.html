01 / Why Harness

Capability without opacity.

An agent should be able to explore, edit, run commands, and delegate—without turning the session into a black box. Harness makes control and observability part of the runtime itself.

[ 01 ]

One authority

The coordinator owns scheduling, permissions, tool execution, hooks, compaction, and lifecycle. There is one place to enforce the rules.

[ 02 ]

Events are truth

Every run becomes contiguous, append-only events. Replay derives state from history without re-running a provider, tool, hook, or network request.

[ 03 ]

Delegation with lineage

Parent agents can launch bounded child tasks while the coordinator preserves ancestry, permissions, status, and durable background results.

02 / Architecture

A narrow waist for agent work.

Interfaces vary. Providers vary. Tools vary. All consequential work still passes through a single event-sourced coordinator.
